Lancer les fichiers depuis le repertoire racine du dépot.

Ce répertoire contient les fichiers utilisés pour la méthode CNN from scratch.
Ils sont répartis par caractéristiques : genre, émotion (classification et regression) et multilabel.
Chaque répertoire contient le fichier pour l'entrainement et le fichier pour lancer la visualisation t-SNE.
Le répertoire multitache contient également un fichier pour faire une cross expérience sur le modèle multiclasse, (entraîner uniuqement sur un des datasets) et un fichier pour générer une playlist.
Le répertoire consommation contient les traces de la consommation du modèle.
